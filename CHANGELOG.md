## [Unreleased]

### Добавлено
- Резервная площадка на TimeWeb (`deploy/timeweb/`): сборка образов на ВМ без реестра Яндекса, подкачка для 1 ГБ памяти, Caddy с HTTPS на https://83-217-223-211.sslip.io.
- Настройка OpenCode: `opencode.json` (инструкции, MCP Linear, GitHub и Playwright, разрешения), агенты `@spec` и `@review`, команды `/task`, `/check`, `/docs`, `/e2e` в `.opencode/`, инструкция подключения `docs/opencode.md`.
- Версия сборки в левом нижнем углу (`HyreKit v0.1.0 · <коммит>`, при наведении — время сборки): на публичных страницах закреплённая подпись, в кабинете — строка внизу боковой панели. Коммит подставляется при сборке; в Docker — аргументом `APP_COMMIT`, `deploy/yc/deploy.sh` передаёт тег выкатки.
- Демо-видео `docs/presentation/HyreKit_demo.mp4` (3 минуты, титры) и скрипт записи `docs/presentation/source/video/` (FSP-58).
- Резервный провайдер LLM YandexGPT (Yandex AI Studio): цепочка `app.llm.chain` опрашивает GigaChat, затем YandexGPT, затем отдаёт результат правилам. Порядок задаёт `LLM_PROVIDERS`, ключи — `YANDEX_GPT_API_KEY`, `YANDEX_GPT_FOLDER_ID`, модель — `YANDEX_GPT_MODEL`. Поле `source` разборов принимает значение `yandexgpt`, подпись в Arena показывает, какая модель написала разбор.
- `GET /api/v1/llm/status`: настроен ли каждый провайдер, ответил ли проверочный запрос, ошибка и задержка (кэш 5 минут).
- README: раздел «Интеграции» со всеми внешними сервисами и разделом про LLM.
- Журнал согласий кандидата с редакцией текста и экран истории в настройках (FSP-25).
- Избранное работодателя: закладка в подборке, банке и карточке, страница «Избранное» с фильтром по потребности (FSP-45).
- `base_total` в ответе подборки — размер до уточняющих фильтров (FSP-45).
- Миграция `0002_consents_favorites`.
- Нагрузочная проверка `scripts/load.py` и отчёт `docs/validation/load.md`: p50/p95 ключевых операций при 10 и 50 пользователях (FSP-56).
- Сопроводительная документация одним файлом: `docs/HyreKit_Documentation.docx` и `.pdf` собираются из `docs/guide/` командой `scripts/build_docs.py`; схемы mermaid рисует `scripts/render_diagrams.cjs` (FSP-57).
- `docs/openapi.json` и `scripts/export_openapi.py`; CI проверяет, что спецификация совпадает с кодом (FSP-57).
- Экспресс-тест для жюри без регистрации: страница `/express`, `POST /api/v1/auth/guest`, 5 заданий за 5 минут, гость сразу попадает в подборку работодателя; переменная `GUEST_MODE` (FSP-32).
- Миграция `0003_express_test` (после `0002_consents_favorites` из FSP-25): `candidate_profiles.is_guest`, `assessment_attempts.mode`.
- Code Arena (FSP-36…FSP-42): задачи по программированию в браузере на Python и JavaScript, редактор CodeMirror с черновиками, запуск на примерах и отправка на скрытые тесты, вердикт и время по каждому тесту, разбор решения GigaChat или правилами со статическим разбором кода (с резервом YandexGPT).
- Песочница Arena: каждый тест — отдельный процесс под rlimit, Landlock (только чтение, без TCP) и seccomp (без сокетов, новых процессов, сигналов и записи файлов), для Python ещё аудит-хук; `GET /api/v1/arena/sandbox` показывает включённые слои (FSP-37).
- Банк из 8 задач трёх уровней с вариантом на участника, эталонным решением и большими тестами; эталоны проходят все тесты в CI (FSP-39).
- Раунды: открытый с личным таймером и раунды по расписанию с заморозкой таблицы, очки ICPC, таблица в реальном времени через SSE, разбор задач после конца участия (FSP-40).
- Рейтинг Arena по Glicko-2 и антисписывание по нормализованным токенам; витрина работодателя, раунд компании, приглашение из таблицы, анонимное участие по умолчанию (FSP-41, FSP-42).
- Пиковая память решения меряется у самого решения: обёртка песочницы запускает его дочерним процессом и передаёт rusage по каналу, поэтому RSS процесса приложения больше не даёт ложный MLE.
- Миграция `0005_code_arena`: таблицы `arena_rounds`, `arena_participants`, `arena_submissions`, `arena_ratings`. В образ приложения добавлен Node.js для решений на JavaScript.

- Мониторинг утечек заданий (FSP-33): статистика семейств по завершённым попыткам, дрейф решаемости относительно модели Раша, исключение утёкших семейств из выдачи, сдвиг трудности; пересчёт раз в `CALIBRATION_INTERVAL_MINUTES`, отчёт `scripts/calibrate.py`, раздел 6 валидации. Миграция `0006_item_calibration`.

- Вход и привязка через ФСП ID по OpenID Connect (Authorization Code + PKCE): кнопка «Войти через ФСП ID», страница `/fsp-callback`, «Привязать через ФСП ID» в настройках, отметка «подтверждён ФСП ID» у достижений; встроенный тестовый провайдер `/api/v1/fsp-id`, переменные `FSP_OIDC_*` (FSP-20).
- Миграция `0007_fsp_oidc`: `candidate_profiles.fsp_sub`.

- Сквозной браузерный тест демо-сценария `scripts/e2e.cjs` на Playwright: новые кандидаты с ФСП и без проходят опрос и тест в интерфейсе, работодатель создаёт потребность, приглашает демо-кандидата из подборки, тот принимает, контакты раскрываются; работает локально и против https://hyrekit.ru (`--base`) (FSP-56).
- Питч на 10 минут в стиле ФСП: `docs/presentation/HyreKit_pitch.pptx` с заметками докладчика и `HyreKit_pitch.pdf`, скриншоты стенда в `docs/presentation/assets/`; инструкция для жюри `docs/jury.md` (FSP-58).

### Изменено
- Порог грейда строже: грейд подтверждается только при большинстве верных ответов (6 из 10 в полном тесте, 3 из 5 в экспресс-тесте). Порог `cut(g)` сдвинут на `CUT_OFFSET`, априорное θ центрировано на пороге проверяемого грейда; раньше Intern подтверждался при 0 из 5, Middle при 4 из 10 (FSP-61).
- Миграция `0004_strict_grade_cut` переносит сохранённые θ на новую шкалу.
- Компонент подборки «ФСП» стал «ФСП и Arena»: берётся больший из балла ФСП и балла рейтинга Arena, в причинах появляется строка Arena (FSP-42).
- Документация сверена с кодом: схема БД, контракт API, переменные окружения, статус площадки, методика и счётчики тестов (FSP-57).
- LLM: терпимый разбор JSON ответа модели (блок кода, перевод строки внутри строки, лишняя запятая, одинарные кавычки), тематический фильтр GigaChat считается ошибкой, `GET /llm/status` показывает `last_error` — последнюю ошибку провайдера в рабочих запросах.
- Презентация пересобрана на официальном шаблоне ФСП «ЛЦТ 2026»: 23 слайда с заметками докладчика, реальные экраны стенда (Code Arena, ФСП ID, мобильная версия), диаграммы валидации и подбора, QR-коды стенда и репозитория; скрипты сборки в `docs/presentation/source/` (FSP-58).

### Исправлено
- Сверка документации и презентации с ТЗ: 43 теста фронтенда вместо 39 (README, раздел 7, слайд 21); точность подборки 0.90 и совпадение решений 60.5 % — как в `docs/validation/results.md`; на слайде 14 названы фильтры, которые есть в подборке; в таблицу критериев добавлен критерий «Презентация и выступление»; в ссылки документации — презентация и демо-видео; исправлены якорь «Как читать за 10 минут», ссылка в `.github/SECURITY.md` и докстринг `matching/service.py`.
- `cryptography` закреплена версией в `requirements.txt` и добавлена в раздел 6.
- Swagger UI, ReDoc и `/openapi.json` открываются на hyrekit.ru: nginx фронтенда проксирует их в API, раньше на `/docs` открывалась страница 404 SPA; `/docs` отдаётся без перенаправления на `/docs/`, которое уводило на внутренний адрес API.
- Кандидат видит число откликов у вакансии: список `GET /candidate/vacancies` отдавал 0.
- На телефоне версия сборки видна внизу страницы кабинета, а не только в закрытом меню.
- Склонения: «Приглашение не найдено», «Вакансия не найдена»; стаж в PDF-профиле — «3 года», «6 лет».
- `scripts/smoke.py` берёт короткое задание демо-работодателя: на живом стенде задания публикуют и другие компании, и проверка падала на чужом задании.

- Тест сразу завершался по таймеру в браузерах с поясом восточнее UTC (Москва — на 3 часа): время из API без пояса читалось как местное. `parseServerDate` во фронтенде читает такое время как UTC; это же исправляет показ дат и сроков.
- Экран результата не пишет «Присвоена категория» и «Категория подтверждена», если тест не сдан: показывается категория прошлого теста и совет пересдать.
- Кнопка «Пригласить» неактивна только пока предыдущее приглашение ждёт ответа, как и проверка на бэкенде: принявшего или отклонившего кандидата можно пригласить снова (FSP-56).
- Вкладка, открытая до выкладки, не открывала разделы кабинета (в том числе «Тестирование»): старые чанки страниц пропадали с сервера. Теперь `index.html` отдаётся с `Cache-Control: no-cache`, а при ошибке загрузки чанка страница один раз перезагружается и получает новую сборку.

## [0.1.0] — 2026-10-10

Первая версия к сдаче хакатона ФСП.

### Добавлено
- Кабинет кандидата: профиль, разбор PDF-резюме (GigaChat или правила), настройки приватности, привязка ФСП ID, PDF-профиль (FSP-22…FSP-26).
- Тестирование на грейд: опрос, 36 параметрических семейств по 14 темам, план 5 тем × 2 задания, оценка θ по модели Раша, решение о категории, пересдача через 90 дней (FSP-27…FSP-30).
- Рейтинг внутри категории и балл ФСП из эмулятора реестра (FSP-26, FSP-43).
- Кабинет работодателя: компания, потребности, подборка с объяснимым баллом и фильтрами, банк кандидатов, тест под вакансию (FSP-43…FSP-45).
- Приглашения с вилкой зарплаты, отклики, раскрытие контактов после согласия (FSP-46, FSP-50).
- Короткие задания компании с оценкой ответа (FSP-51).
- Подтверждение почты по ссылке, Mailpit в docker-compose.
- Демо-аккаунты и синтетический банк из 120 кандидатов (FSP-17).
- Скрипт валидации методики и отчёт `docs/validation/results.md` (FSP-54, FSP-55).
- Интерфейс в фирменном стиле ФСП с анимациями, адаптив от 360 px; официальный кириллический логотип ФСП в шапке, кабинете, на входе и в подвале.
- Сопроводительная документация `docs/guide/`, спецификации, ADR 0001–0007, runbook, схема данных.
- CI: ruff, pytest с покрытием, валидация, сборка и тесты фронтенда.
- Дымовая проверка развёрнутого стенда `scripts/smoke.py`: 28 шагов сквозного сценария через живой API и Mailpit.
- Исправлена выкатка в Yandex Cloud: скрипт запуска ВМ идёт в base64 (yc подставлял переменные окружения), A-записи Timeweb правятся на месте, правило SSH получает `SSH_CIDR`; новые `SKIP_BUILD`, `DISK_TYPE`, `DISK_SIZE` (FSP-18, FSP-34).
- Выкатка в Yandex Cloud одной командой `deploy/yc/deploy.sh`: Container Registry, ВМ с cloud-init без SSH, A-записи в Timeweb, дымовая проверка (FSP-18, FSP-34).
