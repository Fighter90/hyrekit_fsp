# CONTEXT.md — словарь предметной области

Рабочий словарь терминов. В коде, интерфейсе и документации используются слова из колонки «Термин»; синонимы из колонки «Не использовать» путают читателя.

| Термин | Что значит | В коде | Не использовать |
| -- | -- | -- | -- |
| Направление | Специализация: Backend, Frontend, Data Science / ML, DevOps / SRE, QA / Тестирование, Информационная безопасность | `catalog.data.SPECIALIZATIONS` | профессия, трек |
| Грейд | Уровень: Intern, Junior, Middle, Senior, Lead | `catalog.GRADES`, `order` 0–4 | уровень сотрудника, ранг |
| Категория | Пара «направление · грейд», подтверждённая тестом | `CandidateProfile.category_*` | статус, бейдж |
| Опрос | Анкета перед тестом: отрасль, направление, стаж, стек, предполагаемый грейд | `candidates/router.py` `survey` (`POST /candidate/assessment/survey`) | анкета-скрининг |
| Попытка | Одно прохождение теста на конкретный грейд | `AssessmentAttempt` | сессия, экзамен |
| Семейство | Параметрический шаблон задания; из него генерируется задание по зерну | `bank.family` | вопрос, шаблон вопроса |
| Генеративное семейство | Ответ вычисляется из случайных данных, шпаргалка не переносится | `conceptual=False` | — |
| Концептуальное семейство | Проверяет понятие; варианты повторяются, в попытке не больше одного | `bank.CONCEPTUAL` | теоретический вопрос |
| Дрейф семейства | Насколько доля верных ответов выше ожидаемой по модели Раша, за вычетом общего сдвига | `calibration.family_stats` | рост решаемости |
| Утечка семейства | Дрейф и z выше порогов: семейство исключается из выдачи | `ItemCalibration.excluded` | слив вопроса |
| План попытки | 5 тем × 2 задания с уровнями сложности | `engine.build_blueprint` | билет |
| Экспресс-тест | Укороченная попытка для жюри: 5 тем × 1 задание, тот же банк и оценка | `AssessmentAttempt.mode = 'express'` | мини-тест, демо-тест |
| Гость | Кандидат, созданный экспресс-тестом без регистрации; сдаёт только экспресс-тест, без кулдауна | `CandidateProfile.is_guest` | анонимный пользователь |
| θ (способность) | Оценка способности кандидата по модели Раша | `engine.estimate_ability` | IQ, балл |
| Порог грейда | `cut(g) = order − CUT_OFFSET` (Intern −1.75 … Lead 2.25), около 60 % верных ответов на уровне грейда; θ не ниже порога — грейд подтверждён, выше следующего порога на 0.35 — совет попробовать уровень выше | `engine.cut`, `CUT_OFFSET`, `UPGRADE_MARGIN` | проходной балл |
| Рейтинг | Место кандидата внутри своей категории, 0–100 | `candidates.service.rating`, `rating_breakdown` | скоринг |
| Балл ФСП | 0–100 из уровня соревнования, места, давности и профильности | `fsp.provider.summarize` | очки ФСП |
| ФСП ID | Идентификатор участника в реестре ФСП, формат `FSP-NNNN…` | `fsp_id` | логин ФСП |
| Подтверждённый ФСП ID | ФСП ID, привязанный входом через ФСП ID (OpenID Connect): владение проверил провайдер | `fsp_sub`, `FspSummary.verified` | ФСП ID, введённый вручную |
| Потребность | Вакансия работодателя, для которой строится подборка | `Vacancy` | заявка, позиция |
| Подборка | Кандидаты под потребность по убыванию соответствия с объяснением | `matching.service.match_vacancy` | выдача, лента |
| Соответствие | Балл 0–100: категория 30 %, стек 30 %, тест 25 %, ФСП и Arena 10 %, свежесть 5 % | `WEIGHTS` | match score |
| Тест под вакансию | Темы из стека потребности и два варианта равной сложности | `assessment/vacancy.py` | кастомный тест |
| Приглашение | Предложение работодателя кандидату с описанием и вилкой зарплаты | `Invitation` | оффер |
| Отклик | Ответ кандидата на опубликованную вакансию | `Application` | заявка |
| Короткое задание | Практическое задание компании, ответ оценивается моделью (GigaChat, резерв YandexGPT) или правилами | `Challenge` | челлендж (только в интерфейсе) |
| Согласие | Разрешение кандидата на обработку и показ профиля работодателям; выдача и отзыв пишутся в журнал с редакцией текста | `ConsentEvent`, `CONSENT_VERSION` | галочка, opt-in |
| Избранное | Шортлист компании: отмеченные кандидаты, при желании под потребность | `Favorite` | закладки, вишлист |
| Code Arena | Соревнования по коду: задачи с автопроверкой на скрытых тестах, раунды, рейтинг | `app/arena` | контест, олимпиада |
| Раунд | Набор задач с таймером: открытый (таймер у каждого свой) или по расписанию (общий старт и конец, заморозка таблицы) | `ArenaRound` | турнир, сессия |
| Вариант задачи | Условие и тесты задачи для конкретного участника, генерируются по зерну раунда, участника и задачи | `problems.variant` | билет |
| Отправка | Решение, проверенное на всех тестах варианта; запуск на примерах отправкой не считается | `ArenaSubmission` | посылка, сабмит |
| Вердикт | Итог проверки: OK, WA, TLE, MLE, RE, CE | `judge.VERDICT_TITLES` | статус решения |
| Песочница | Запуск решения под rlimit, Landlock и seccomp (для Python ещё аудит-хук) | `arena/sandbox.py`, `judge.py` | контейнер решения |
| Разбор решения | Объяснение результата: где упало, нужная сложность, замечания по коду; пишет модель (GigaChat, резерв YandexGPT) или правила | `arena/feedback.py` | ревью, фидбек |
| Провайдер LLM | Внешняя модель, которая пишет разборы и оценки: GigaChat, при его отказе YandexGPT; если не ответил никто — правила. Кто написал результат, видно в `source` | `app/llm/chain.py` | ИИ, нейросеть |
| Рейтинг Arena | Glicko-2 по участиям, соперники — задачи; предварительный, пока неуверенность велика; входит в компонент «ФСП и Arena» подборки | `arena/rating.py`, `matching.service.arena_score` | ELO, очки |
| Раскрытие контактов | ФИО и контакты видны работодателю после принятия приглашения или отклика | `hiring.service` | — |
