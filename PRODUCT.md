# PRODUCT.md — HyreKit

Короткое описание продукта для людей и агентов. Подробно — [docs/guide/01-produkt.md](docs/guide/01-produkt.md).

## Platform

Веб-приложение: адаптивный SPA (React) для телефона и ПК поверх REST API (FastAPI). Площадка работает на <https://hyrekit.ru> в Yandex Cloud. Два кабинета (кандидат и работодатель) и публичный лендинг.

## Users

| Роль | Кто | Что делает |
| -- | -- | -- |
| Кандидат | ИТ-специалист, часто участник соревнований ФСП | Заполняет профиль, проходит тест на грейд, получает категорию, принимает приглашения, откликается на вакансии |
| Работодатель | Рекрутер или тимлид ИТ-компании | Описывает потребность, получает подборку с объяснением, смотрит тест под вакансию, приглашает кандидатов |

## Product Purpose

Обратная механика найма: не кандидат ищет вакансию, а работодатель находит кандидата в банке проверенных профилей. Заявленный грейд подтверждается тестом, достижения ФСП подтягиваются из реестра, поэтому работодатель сравнивает кандидатов по проверенным данным, а не по тексту резюме.

## Positioning

Агрегатор ИТ-вакансий с верифицированным профилем достижений участника ФСП. Отличие от досок вакансий — категория «направление · грейд», подтверждённая тестом, который нельзя выучить по утёкшим ответам, и прозрачный балл соответствия с разбивкой по компонентам.

## Operating Context

- Хакатон ФСП, трек «Цифровая платформа-агрегатор ИТ-вакансий с верифицированным профилем достижений участника ФСП», сдача 10.10.2026.
- API реестра ФСП не предоставлен: интеграция через интерфейс `FspProvider` и детерминированный эмулятор.
- LLM — цепочка GigaChat → YandexGPT → правила; без ключей все функции работают на правилах.
- Персональные данные по 152-ФЗ: согласие, раскрытие контактов только после принятия приглашения.

## Capabilities and Constraints

Есть в MVP:
- регистрация с подтверждением почты, роли, профиль с разбором PDF/DOCX-резюме;
- вход и привязка через ФСП ID (OpenID Connect, встроенный тестовый провайдер, Keycloak ФСП подключается переменными);
- экспресс-тест для жюри: 5 заданий без регистрации;
- тест на грейд: 10 параметрических заданий, оценка по модели Раша, решение о категории, пересдача через 90 дней;
- рейтинг внутри категории, баллы ФСП;
- подборка под потребность с объяснением, фильтры, банк кандидатов, тест под вакансию;
- приглашения с вилкой зарплаты, отклики, короткие задания;
- Code Arena: задачи по коду в браузере, автопроверка в песочнице, рейтинг Glicko-2;
- LLM для разбора резюме, оценки коротких заданий и разбора решений Arena: GigaChat → YandexGPT → правила;
- PDF-профиль кандидата, демо-данные и синтетический банк из 120 кандидатов.

Не входит в MVP: реальный реестр ФСП, модерация работодателей, интеграция с ATS — спроектированы в [docs/guide/04-arhitektura.md](docs/guide/04-arhitektura.md).

## Brand Commitments

- Фирменный стиль ФСП: тёмная основа, синий `#402FFF` и красный `#EC1D35`, шрифты JetBrains Mono и TDAText ([DESIGN.md](DESIGN.md)).
- Тексты на русском, без канцелярита; числа показываются с объяснением, откуда они.
- Ничего не скрывается от кандидата: он видит свой балл, разбор по темам и причину решения.
