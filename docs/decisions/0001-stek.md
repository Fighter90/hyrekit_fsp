# 0001. Модульный монолит: FastAPI + PostgreSQL + React

**Дата.** 2026-10-09

**Контекст.** До сдачи сутки, в команде один разработчик бэкенда. ТЗ 3.5 допускает монолит с явным разделением слоёв, требует OpenAPI и воспроизводимый запуск, рекомендует открытое ПО.

**Решение.** Бэкенд — FastAPI 0.115 с async SQLAlchemy 2.0 и PostgreSQL 16, модули по предметным областям (`auth`, `candidates`, `assessment`, `matching`, `employers`, `hiring`, `challenges`, `fsp`). Фронтенд — React 19 + Vite + TypeScript. Запуск — Docker Compose.

**Альтернативы.**
- Микросервисы — дороже в разработке и развёртывании без выигрыша на объёмах MVP.
- Django — быстрее админка, но OpenAPI и async хуже из коробки.
- Next.js с API-роутами — один язык, но методика на Python удобнее для численных расчётов и валидации.

**Последствия.** OpenAPI генерируется автоматически; методика — чистые функции, их переиспользует скрипт валидации. При росте модули выносятся в сервисы по границам `service.py`.
