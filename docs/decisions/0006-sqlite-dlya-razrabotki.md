# 0006. SQLite для локального запуска и тестов, PostgreSQL на площадке

**Дата.** 2026-10-10

**Контекст.** Эксперт должен запустить решение по инструкции; не у всех есть Docker. Тесты должны идти без внешних сервисов.

**Решение.** Модели используют переносимые типы (JSON с вариантом JSONB для PostgreSQL). `scripts/dev.sh` поднимает API на SQLite-файле, тесты — на SQLite в памяти. Docker Compose и площадка — PostgreSQL 16.

**Альтернативы.** Только PostgreSQL — выше порог запуска; testcontainers — медленнее и требует Docker в CI.

**Последствия.** Специфичные для PostgreSQL запросы запрещены в коде модулей; при их появлении — отдельные тесты на PostgreSQL в CI.
