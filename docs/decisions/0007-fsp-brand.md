# 0007. Визуальная система по брендбуку ФСП

**Дата.** 2026-10-09

**Контекст.** ТЗ приветствует решение в цветовой гамме ФСП; критерий интерфейса — 10 %.

**Решение.** Палитра брендбука: основной акцент #402FFF, красный #EC1D35, цифровой акцент #0A006B, серые #1B1C21 / #2D2E37 / #3A3C46 / #9B9C9E / #D9D9D9, белый #EDEDED; тёмные фоны. Шрифты брендбука: JetBrains Mono — основной, TDAText — акцентный (оба SIL OFL), раздаются с собственного домена. Паттерн из кодовых глифов `{ } < / > // ▲ ●`.

**Альтернативы.** Нейтральная светлая тема с UI-китом — быстрее, но не узнаётся как продукт ФСП.

**Последствия.** Моноширинный шрифт требует аккуратной типографики длинных текстов: увеличенный интерлиньяж и ограничение ширины строки. Подробности — DESIGN.md.
