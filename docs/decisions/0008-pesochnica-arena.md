# 0008. Песочница Code Arena на Landlock и seccomp внутри контейнера приложения

**Дата.** 2026-10-10

**Контекст.** Code Arena исполняет чужой код. Решение не должно выйти в сеть, запустить процессы, прочитать файлы стенда или записать на диск. Стенд — одна ВМ с фиксированным compose-файлом; отдельный привилегированный исполнитель или новый контейнер на каждый тест добавляет зависимость от Docker API внутри приложения, а это равносильно root на хосте.

**Решение.** Каждый тест — отдельный процесс `python -I -S -B src/app/arena/sandbox.py <конфиг>`. Обёртка ставит rlimit (процессор, память, размер файлов, открытые файлы, без core), затем Landlock (чтение только каталогов интерпретатора, системных библиотек и папки решения; запись запрещена; на ABI 4+ запрещены TCP bind и connect) и фильтр seccomp (сокеты, fork, clone без CLONE_THREAD, ptrace, сигналы, монтирование, удаление и переименование, открытие на запись), после чего exec интерпретатора. Слои ставятся непривилегированным процессом (`no_new_privs`) и переживают exec. Для Python дополнительно работает аудит-хук `pyboot.py`. JavaScript включается, только если ядро дало оба слоя.

**Альтернативы.**
- Контейнер на каждый тест через Docker API — нужен сокет Docker в приложении, это доступ root к хосту; старт контейнера дольше самого теста.
- Отдельный контейнер-исполнитель без сети — требует менять compose на ВМ и держать второй сервис; выигрыша над Landlock и seccomp на одном ядре нет.
- nsjail или bubblewrap — внешние бинарники и пользовательские пространства имён, которые Docker по умолчанию не разрешает без привилегий.
- Только аудит-хук Python — обходится через C-расширения и не защищает JavaScript.

**Последствия.** Изоляция зависит от ядра: на ядрах без Landlock остаётся rlimit, seccomp и аудит-хук, а JavaScript отключается. `GET /api/v1/arena/sandbox` показывает включённые слои на стенде. Фильтр seccomp написан для x86_64; на другой архитектуре он не ставится, и JavaScript тоже отключается. Java и Go потребуют компиляторов в образе и отдельной проверки слоёв.
