# Сопроводительная документация HyreKit

Документация для жюри хакатона ФСП и для любого человека вне команды. Её задача — чтобы сторонний читатель понял продукт, механику тестирования и подбора и воспроизвёл запуск без пояснений команды (ТЗ, п. 3.4). Трек — «Цифровая платформа-агрегатор ИТ-вакансий с верифицированным профилем достижений участника ФСП», команда «Команда 1».

Версия продукта — **0.1.0** от 10.10.2026. Описано только то, что есть в коде `main`; чего нет, названо прямо: «не входит в MVP».

## Как читать за 10 минут

1. [Раздел 1](01-produkt.md), абзацы «Проблема» и «Обратная механика» — 2 минуты.
2. [Раздел 3](03-metodika-ocenki.md), «Почему тест не утекает» и «Результаты валидации» — 5 минут.
3. [Раздел 5](05-zapusk-i-demo.md), «Демо за 5 минут» — пройти руками.

Полные цифры валидации пересчитываются командой `PYTHONPATH=src python scripts/validate.py` и лежат в [docs/validation/results.md](../validation/results.md).
