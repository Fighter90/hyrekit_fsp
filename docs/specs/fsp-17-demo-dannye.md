# Демо-данные и демо-аккаунты

Linear: FSP-17. Пункты ТЗ: 3.3.

## Цель
Жюри входит и сразу видит живой кабинет работодателя с подборками, а путь кандидата проходит с нуля.

## Правила и числа
- `candidate@hyrekit.ru` и `employer@hyrekit.ru`, пароль `HyreKit2026`, почта подтверждена.
- Компания «ТехноПлатформа», 3 опубликованные вакансии (Backend, Frontend, DevOps), 2 коротких задания.
- 120 синтетических кандидатов по 6 направлениям; грейд и θ — из симуляции теста по модели валидации; 65 % с ФСП ID.
- Сидирование идемпотентно; выключается `SEED_DEMO=false`.

## Критерии приёмки (EARS)
- WHEN приложение стартует с пустой базой THE SYSTEM SHALL создать демо-аккаунты и банк кандидатов.
- WHEN приложение стартует повторно THE SYSTEM SHALL ничего не дублировать.
