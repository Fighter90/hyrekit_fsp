# Достижения ФСП: эмулятор реестра и отображение

Linear: FSP-26, FSP-20 (концепция ФСП ID). Пункты ТЗ: 2, 2.1 «Настройки», 4.

## Цель
Достижения участника ФСП автоматически попадают в профиль и поднимают кандидата внутри категории; кандидат без истории обрабатывается корректно.

## Правила и числа
- ФСП ID формата `FSP-` и 4–8 цифр.
- Эмулятор детерминирован по ID; ID, оканчивающийся на 0, — участник без истории.
- Балл 0–100: 30 × вес соревнования (Кубок и Чемпионат России 1.0, Первенство России 0.8, межрегиональный хакатон 0.7, региональные 0.5) × коэффициент места × давность (−15 % в год, не ниже 40 %); профильная дисциплина весит вдвое больше.
- Вклад в рейтинг внутри категории — 25 %, в балл подборки — 10 %.

## Критерии приёмки (EARS)
- WHEN кандидат привязывает ФСП ID THE SYSTEM SHALL сохранить снимок достижений и пересчитать рейтинг.
- WHEN у ФСП ID нет истории THE SYSTEM SHALL вернуть `has_history: false` и балл 0 без ошибки.
- WHEN ID не соответствует формату THE SYSTEM SHALL вернуть 400.

## Интерфейсы
`PUT /candidate/settings {fsp_id}`, `GET /candidate/fsp`; протокол `fsp.provider.FspProvider.fetch`.
