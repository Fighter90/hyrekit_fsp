# Приглашения с зарплатой: статусы и раскрытие контактов

Linear: FSP-46. Пункты ТЗ: 2.1 «Выход на контакт», «Просмотр приглашений», 2.2.

## Цель
Смысловой центр продукта: работодатель сам выходит на конкретного кандидата с предложением и вилкой.

## Правила и числа
- Приглашение: заголовок, описание предложения, вилка «от–до» в рублях, способ связи, компания; вакансия — необязательно.
- Статусы: отправлено → просмотрено → принято / отклонено (с причиной).
- Пока приглашение компании кандидату не закрыто, второе отправить нельзя (409).
- Принятие раскрывает компании ФИО и контакты кандидата.
- Кандидат видит только свои приглашения, работодатель — только отправленные своей компанией.

## Критерии приёмки (EARS)
- WHEN работодатель отправляет приглашение без зарплаты THE SYSTEM SHALL вернуть 422.
- WHEN кандидат открывает приглашение THE SYSTEM SHALL перевести его в «просмотрено».
- WHEN кандидат принимает приглашение THE SYSTEM SHALL показать компании контакты кандидата.

## Интерфейсы
`POST/GET /employer/invitations`, `GET /candidate/invitations`, `POST /candidate/invitations/{id}/view|accept|decline`.
