# Результаты валидации методики

Сгенерировано `scripts/validate.py`, зерно 20261010. Все кандидаты синтетические: модельный кандидат с истинной способностью θ отвечает верно с вероятностью σ(θ − b).

## 1. Равная сложность вариантов

Для каждого грейда собрано 1 200 случайных вариантов (6 направлений × 200); уровень берётся у сгенерированного задания, а не у плана. Число различных профилей сложности должно быть равно 1.
